# Project Cleanup

## Objective

Remove Azure resources after completing the lab to minimize Pay-As-You-Go costs.

---

## Cleanup Activities

- Deleted Resource Group.
- Deleted Virtual Machine.
- Deleted Network Interface.
- Deleted Public IP.
- Deleted Network Security Group.
- Deleted Storage Account.
- Removed Defender plans where applicable.
- Deleted Diagnostic Settings.
- Verified no billable resources remained.

---

## Result

The Azure environment was successfully cleaned up after project completion while preserving all project documentation and screenshots in GitHub.

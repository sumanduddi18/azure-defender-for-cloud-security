# Scenario-Based Interview Questions

## Scenario 1

A VM has a low Secure Score.

How would you investigate and improve it?

Answer:

- Review recommendations
- Prioritize high-impact recommendations
- Implement remediation
- Verify Secure Score improvement

---

## Scenario 2

A critical Security Alert is generated.

What are your first actions?

- Review alert details
- Identify affected resource
- Verify attack indicators
- Contain the resource
- Begin investigation

---

## Scenario 3

Management asks whether Azure complies with Microsoft Cloud Security Benchmark.

Answer:

Use Regulatory Compliance dashboard to review compliance status and remediation guidance.

---

## Scenario 4

A security recommendation suggests enabling Backup.

Would you enable it immediately?

No.

Evaluate business requirements, recovery objectives, and cost before implementation.

---

## Scenario 5

How would you reduce Azure Security risks?

- Enable Defender Plans
- Review Secure Score
- Implement recommendations
- Review Security Alerts
- Monitor compliance continuously

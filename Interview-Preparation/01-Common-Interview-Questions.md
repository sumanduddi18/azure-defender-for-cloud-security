# Microsoft Defender for Cloud - Common Interview Questions

## 1. What is Microsoft Defender for Cloud?

Microsoft Defender for Cloud is Azure's Cloud Security Posture Management (CSPM) and Cloud Workload Protection Platform (CWPP) solution that helps secure Azure, hybrid, and multi-cloud environments.

---

## 2. What is Secure Score?

Secure Score measures the security posture of Azure resources and provides recommendations to improve security.

---

## 3. What is the difference between CSPM and CWPP?

CSPM focuses on identifying misconfigurations and improving cloud security posture.

CWPP protects workloads such as Virtual Machines, SQL, Storage, Containers, and App Services.

---

## 4. What are Security Recommendations?

Recommendations identify security weaknesses and provide remediation guidance.

---

## 5. What is Attack Path Analysis?

Attack Path Analysis identifies possible paths an attacker could use to compromise Azure resources.

---

## 6. What is Regulatory Compliance?

It evaluates Azure resources against built-in security standards and compliance frameworks.

---

## 7. What is Continuous Export?

Continuous Export streams Defender findings to Log Analytics, Event Hub, or SIEM platforms.

---

## 8. What is Workflow Automation?

Workflow Automation automatically triggers Logic Apps based on Defender alerts or recommendations.

---

## 9. Which Defender Plan was enabled?

Microsoft Defender for Servers Plan 2.

---

## 10. Why was Defender disabled after the project?

To avoid unnecessary Pay-As-You-Go charges after completing the lab.

# Technical Concepts

## Cloud Security Posture Management (CSPM)

Continuously evaluates Azure resources for security misconfigurations.

---

## Cloud Workload Protection Platform (CWPP)

Provides workload protection for Azure Virtual Machines and supported services.

---

## Secure Score

Measures Azure security posture.

---

## Security Recommendations

Provides remediation guidance for improving Azure security.

---

## Attack Path Analysis

Identifies possible attack paths between Azure resources.

---

## Regulatory Compliance

Maps Azure resources against industry security standards.

---

## Security Alerts

Detect suspicious activities within Azure resources.

---

## Workflow Automation

Automates security response using Logic Apps.

---

## Continuous Export

Exports security findings to monitoring solutions.

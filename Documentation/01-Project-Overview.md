# Project Overview

## Objective

The objective of this project is to implement Microsoft Defender for Cloud to improve the security posture of Azure resources through continuous security assessment, threat detection, attack path analysis, regulatory compliance, and cloud workload protection.

---

## Project Scope

This implementation covers:

- Microsoft Defender for Cloud Setup
- Defender Plans
- Secure Score
- Security Recommendations
- Attack Path Analysis
- Security Alerts
- Workflow Automation
- Continuous Export
- Cleanup

---

## Services Used

- Microsoft Defender for Cloud
- Azure Monitor
- Log Analytics
- Azure Resource Manager
- Azure Resource Groups
- Azure Virtual Machines
- Virtual Networks
- Storage Accounts

---

## Skills Demonstrated

- Cloud Security
- Security Posture Management
- Threat Detection
- Compliance Monitoring
- Azure Governance
- Cloud Security Best Practices
- Security Operations

---

## Outcome

Successfully implemented Microsoft Defender for Cloud, analyzed security posture, reviewed recommendations, explored attack path analysis, configured monitoring features, and documented enterprise cloud security practices.

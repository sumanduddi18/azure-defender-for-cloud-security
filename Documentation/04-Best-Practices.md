# Microsoft Defender for Cloud Best Practices

- Enable Defender Plans only for required workloads.
- Continuously improve Secure Score.
- Review recommendations weekly.
- Investigate security alerts promptly.
- Configure email notifications.
- Automate remediation where appropriate.
- Export security data to SIEM solutions.
- Monitor regulatory compliance.
- Apply least privilege access.
- Enable logging and monitoring.
- Review attack paths regularly.
- Remove unused Azure resources.
- Follow Microsoft security baselines.
